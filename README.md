DOKUMENTASI PEMBUATAN WEBSITE PERSONAL PORTFOLIO AMELIA PUSPITASARI

Pendahuluan
Website Personal Portfolio Amelia Puspitasari dibuat menggunakan HTML5 dan CSS3. Website ini dirancang sebagai media untuk memperkenalkan identitas diri, riwayat pendidikan, keterampilan, pengalaman kerja, proyek, aktivitas, serta informasi kontak.

Pembuatan website dilakukan secara bertahap dengan menggunakan struktur HTML5 yang semantik dan desain CSS3 yang responsif. Setiap bagian dikembangkan untuk menghasilkan tampilan website yang menarik, terstruktur, dan mudah digunakan oleh pengunjung.

TAHAP PEMBUATAN CSS3

Tahap 1 – Membuat Variabel, Pengaturan Dasar, dan Header Website
Penjelasan:
Tahap pertama merupakan pengaturan dasar tampilan website menggunakan CSS3.
1. :root digunakan untuk membuat variabel warna, jenis font, bayangan, dan ukuran sudut elemen agar desain website konsisten.
2. Universal selector digunakan untuk mengatur perhitungan ukuran seluruh elemen menggunakan box-sizing.
3. Selector html dan body mengatur perilaku scroll, warna teks, latar belakang, jenis huruf, dan jarak antarbaris.
4. .section-wrap dan .section-block mengatur lebar konten serta jarak antarbagian website.
5. .site-header membuat header tetap berada di bagian atas ketika halaman digulir.
6. .header-inner mengatur posisi logo, navigasi, dan tombol menggunakan Flexbox.
7. .brand, .brand-mark, dan .brand-name mengatur desain logo Amelia.
8. .main-nav mengatur susunan menu navigasi.
9. .header-contact mengatur tampilan tombol Let’s Connect beserta efek hover.

Tahap 5 – Mengatur Contact, Footer, Responsive Design, dan Tambahan UTS
Penjelasan:
Tahap kelima merupakan tahap akhir pengaturan CSS. Bagian ini mengatur tampilan kontak, footer, responsivitas website, serta tambahan desain untuk memenuhi kebutuhan tugas UTS HTML5 dan CSS3.
1. .contact-section mengatur latar belakang bagian kontak menggunakan gradasi warna pink dan hijau.
2. .contact-inner mengatur susunan informasi kontak menggunakan CSS Grid.
3. .contact-links mengatur tampilan tautan email, Instagram, dan GitHub beserta efek hover.
4. .site-footer dan .footer-inner mengatur bagian penutup website yang berisi logo, identitas pembuat, tahun, dan tautan kembali ke atas.
5. @media (max-width: 900px) digunakan untuk menyesuaikan tampilan website pada layar tablet.
6. @media (max-width: 680px) digunakan untuk menyesuaikan tampilan website pada layar ponsel. Beberapa kolom diubah menjadi satu kolom agar konten lebih mudah dibaca.
7. @media (prefers-reduced-motion: reduce) mengurangi efek animasi bagi pengguna yang memilih pengaturan gerakan minimal pada perangkatnya.
8. .table-scroll dan .portfolio-table mengatur tampilan tabel pendidikan dan pengalaman kerja, termasuk kemampuan menggulir tabel secara horizontal.
9. .skill-list-wrap dan .skill-list mengatur kotak ringkasan keterampilan.
10. .media-section, .media-grid, dan .media-card mengatur tampilan kartu audio dan video.
11. .contact-form mengatur tampilan formulir pesan, termasuk kolom input, textarea, tombol kirim, dan efek ketika kolom dipilih.
